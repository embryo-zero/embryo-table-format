# Embryo Table Format

Embryo Table Format is Embryo-Zero's fork of [iceberg](https://github.com/apache/iceberg) (a6bc1f9, commit a6bc1f9). It does open table format for data lakes.

- Our changes live on the `embryo` branch. The original license files (LICENSE, NOTICE) are unchanged.
- Legal notes: LEGAL.md. Dated list of our changes: CHANGES-EMBRYO.md.
